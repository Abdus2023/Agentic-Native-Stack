# agentic-core

Rust workspace for the agentic-native stack.

## Crates

| Crate | Purpose |
|---|---|
| `agentic-pty` | Cross-platform PTY management |
| `agentic-ssh` | SSH client/server abstractions |
| `agentic-vte` | Terminal parsing and shadow parser |
| `agentic-tunnel` | Transport abstraction |
| `agentic-session` | Session multiplexer |
| `agentic-agent-core` | Agent loop, tools, and permissions |
| `agentic-memory` | Memory system |
| `agentic-event` | Typed event bus |
| `agentic-protocol` | Shared protocol types |
| `agentic-daemon` | Daemon executable |
