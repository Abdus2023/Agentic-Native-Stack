# RFC Process

Major changes should go through the RFC process.

## When an RFC Is Required

Protocol changes, permission model changes, security-boundary changes, storage schema changes, new crates or packages, breaking API changes, and major architectural changes require an RFC.

## Lifecycle

```text
Draft → Review → Accepted / Rejected → Implemented → Released
```

Copy `template.md` to `NNNN-title.md`, open a pull request, request maintainer review, and record the outcome in the RFC status.
